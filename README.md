# GSAT 나의 페이스

수리 30분 → 휴식 5분 → 추리 30분을 자동 진행하는 타이머와, 분:초만 표시하는 문제별 스톱워치입니다. 두 도구는 독립 탭에서 동작합니다. 외부 라이브러리 없이 `index.html` 한 파일로 실행됩니다.

## iPad에서 사용하기

iPad **파일 앱의 HTML 미리보기는 웹브라우저 실행 환경이 아닙니다.** 스크립트와 오디오 실행이 제한되므로, 미리보기에서는 타이머나 알림이 동작한다고 가정하면 안 됩니다. HTML 파일에서 이 제한을 해제할 수 없습니다.

iPad에서는 게시된 페이지의 웹 주소를 Safari로 여세요. `소리 확인`을 한 번 누르고, 페이지의 음량 바와 iPad 기기 음량을 맞추세요. Safari의 공유 메뉴에서 `홈 화면에 추가`를 선택하면 다음에도 같은 웹페이지를 쉽게 열 수 있습니다. HTML 파일 저장은 웹페이지 주소로 접속하는 것과 다릅니다.

다른 앱이나 잠금 화면에서 돌아오면 실제 경과 시간을 반영합니다. iPadOS가 배경 오디오를 중단할 수 있으므로 시험 중에는 화면을 켜 두세요. 복귀 후 소리가 중단되었다는 안내가 보이면 `소리 확인`을 다시 누르세요.

## Safari용 웹페이지 게시

이 저장소에는 수동 실행 전용 GitHub Pages 작업을 준비했습니다. 파일을 수정하거나 저장하는 것만으로는 공개 게시되지 않습니다.

1. 변경 내용을 검토한 뒤 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
3. **Actions → Publish GSAT timer → Run workflow**를 실행합니다.
4. 완료된 작업의 배포 주소를 iPad Safari에서 엽니다. 실제 배포가 끝나기 전에는 사용 가능한 웹 주소가 생성되었다고 가정하지 마세요.

이 작업은 `index.html`만 게시합니다. 공개 페이지에는 HTML 소스가 노출됩니다.

## 컴퓨터에서 실행

브라우저에서 HTML을 직접 열거나, 저장소 폴더에서 `python3 -m http.server 4173`을 실행해 테스트할 수 있습니다. 컴퓨터의 localhost 주소는 iPad에서 같은 컴퓨터를 가리키지 않습니다. iPad에서 접속하려면 배포된 웹 주소 또는 접근 가능한 웹서버 주소가 필요합니다.

진행 상태와 음량은 브라우저 저장소를 사용할 수 있을 때 저장됩니다. 모바일의 `HTML 저장`은 지원되는 경우 기본 공유 메뉴를 통해 파일을 저장하고, 그 외에는 일반 다운로드를 사용합니다.
